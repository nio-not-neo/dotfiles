# archive

Settings, snippets and notes from tools I no longer use (iTerm2, Warp, kitty, fish). Nothing here is applied to `$HOME`.

Use it as a source for migration. When something is worth keeping, port it to the active tool under `dot_config/` and note it in `docs/`.

Layout: `archive/<tool>/`. Scrub secrets and employer-specific content before adding anything, because this repo is public.
